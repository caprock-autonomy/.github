# Caprock Autonomous Technologies

**American autonomous systems, robotics hardware, and embedded motion-control technology from West Texas.**

Caprock Autonomous Technologies develops open and practical robotics systems, including robot control boards, motor-driver hardware, power electronics, ROS 2 software, embedded firmware, simulation tools, and educational robotics platforms.

## Focus Areas

- Robot control boards
- Embedded motion-control systems
- ROS 2 mobile robot platforms
- Motor-driver and power electronics hardware
- micro-ROS firmware
- UAV and ground robot simulation
- Robotics education and laboratory platforms

## Product Families

- **CAT Core** — robot controller boards
- **CAT Drive** — motor-driver boards
- **CAT Power** — battery and power-distribution boards
- **CAT Rover** — mobile robot platforms
- **CAT Air** — UAV and drone systems
- **CAT ROS** — ROS 2 software packages
- **CAT Edu** — teaching kits and robotics labs

## Origin

Built in West Texas with a focus on rugged, practical, field-ready robotics and control systems.
